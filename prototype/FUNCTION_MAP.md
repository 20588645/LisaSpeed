# LisaSpeed 全站功能地图（HTML 原型）

> 已选定 **Tech** 视觉。信息架构按 **LisaSpeed 产品使用路径** 重组，不再镜像 Hiddify 工程分类。

## 1. 产品目标

面向 Apple Silicon Mac 的本地加速客户端。日常路径：

**选订阅 → 选节点 → 选模式 → 一键连接**；需要时再进设置调分流/高级项，出问题再看日志。

## 2. 相对原软件的调整

| 原 Hiddify 式分类 | LisaSpeed 调整 | 原因 |
|------------------|----------------|------|
| 侧栏「代理 / 配置 / 设置 / 日志 / 关于」六项并列 | 侧栏只留 **主页 · 节点 · 订阅 · 设置** | 降低决策面；日志/关于归入设置 |
| 设置拆成 链 / 路由 / DNS / 入站 / TLS 五张平铺卡 | 改为 **通用 · 连接 · 分流 · 高级 · 诊断 · 关于** | 按用户心智，不按内核模块 |
| 「配置文件」 | 改称 **订阅** | 更贴近用户说法 |
| 「代理」 | 改称 **节点** | 强调选线路，而非协议概念 |
| 「入站」单独页 | 并入 **连接** | 端口/共享/严格路由都是连接相关 |
| 链 / DNS / TLS 各一页 | 并入 **高级**（同页分区） | 低频，避免顶栏膨胀 |
| 「路由」 | 改称 **分流** | 国内用户更易理解 |

## 3. 页面清单

### 侧栏（一级）

| ID | 名称 | 用户目标 |
|----|------|----------|
| `home` | 主页 | 连接/断开、模式、当前订阅、流量摘要 |
| `nodes` | 节点 | 选线路、测延迟 |
| `subscriptions` | 订阅 | 管理订阅/本地配置 |
| `settings` | 设置 | 进入各设置分区 |

### 二级 / 浮层

| ID | 名称 | 入口 |
|----|------|------|
| `subscription-detail` | 订阅详情 | 订阅 → 编辑 |
| `settings-general` | 通用 | 设置 |
| `settings-connection` | 连接 | 设置 |
| `settings-routing` | 分流 | 设置 |
| `settings-rule` | 规则编辑 | 分流 |
| `settings-advanced` | 高级 | 设置（DNS / TLS / 链路增强） |
| `logs` | 诊断 · 日志 | 设置 |
| `about` | 关于 | 设置 |
| `modal-add-profile` | 添加订阅 | 主页 / 订阅 |
| `modal-confirm` | 确认删除 | 订阅 |

## 4. 跳转关系

```
壳(侧栏)
├── 主页 ──[+ 添加订阅]──► 弹层
│        ──[当前订阅]──► 订阅
│        ──[模式分段]──► 页内切换
│        ──[打开节点列表]──► 节点
├── 节点
├── 订阅 ──[编辑]──► 订阅详情
│        ──[添加]──► 弹层
└── 设置 ──► 通用 | 连接 | 分流 | 高级 | 诊断 | 关于
              分流 ──► 规则编辑
```
